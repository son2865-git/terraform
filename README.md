# 간병보험 안내

## 간병보험이란?

간병보험(간병인보험/간병비보험)은 상해·질병으로 인해 입원하거나 장기요양이 필요한 경우 간병비용을 보장해 주는 보험입니다.

---

## 월평균 보험료 (2024년 기준)

| 연령대 | 월 보험료 (여성, 건강체, 100세 만기) |
|--------|--------------------------------------|
| 30대   | 약 29,000원                          |
| 40대   | 약 36,000원                          |
| 50대   | 약 44,000원                          |

> **참고사항**
> - 남성이나 유병력자는 상품별로 10~20% 내외 보험료 차이가 발생합니다.
> - 연령이 증가할수록 보험료가 가파르게 오릅니다.
> - **체증형 상품**(보장금액이 기간에 따라 자동 인상)은 일반형 대비 월 3,000~10,000원가량 보험료가 더 높습니다.
> - 남녀, 직업, 유병력 여부에 따라 변동 폭이 크므로 가입 전 설계안 제출이 필요합니다.

---

## 주요 보장 내용

### 1. 간병비 일당 (정액 지급)
상해·질병 등으로 입원하여 간병이 필요한 경우 지급됩니다.

| 구분 | 일당 보장금액 | 최대 보장일수 |
|------|---------------|---------------|
| 일반병원 | 1일 15만 원 | 최대 180일 |
| 요양병원 | 1일 5만 원 | 최대 180일 |
| 간호간병통합병동 | 1일 7만 원 | 최대 180일 |

- 가족이 직접 간병하더라도 일당 보험금 지급 가능 (간호일지·간병계약서 등 증빙 필요)
- 일부 보험사 상품은 가족 간병 인정이 제한될 수 있음

### 2. 간병인 지원 서비스 (실제 제공)
- 질병이나 상해 입원 시 보험사가 간병인 파견 (보장금액 보통 1일 8만 원, 최대 180일)
- 보험사 지정 간병인만 파견 가능 (가족 간병 불인정)

### 3. 생활자금 / 장기요양 특약
- 장기요양등급(1~3등급) 판정 시, 매월 50~100만 원의 생활자금 지급
- 치매·중풍 등 중증 질환 시 진단금(1회 500만~1,000만 원) 지급 특약 포함 가능

### 4. 기타 선택 특약
- 재택 간병비
- 시설 입소비
- 간병휴직 소득 보전
- 상황별 특약 선택 가능

---

## 알아두어야 할 사항

- 보장은 대부분 **가입 후 90일** 면책 기간 경과 후 개시
- 영수증, 간병일지 등 **증빙서류 필수** (가족 간병 보장은 최근 약관 개정으로 점차 제한되는 추세)
- 정해진 일당 지급(정액형) vs. 실비(실제비용) 지원 상품 구분 필요
- 최대 보장 일수(90일, 180일, 365일 등) 선택에 따라 보험료가 달라짐
